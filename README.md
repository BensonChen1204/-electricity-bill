# 宜蘭租屋小幫手

正式版單頁 PWA，供宜蘭出租屋每月結算使用。

## 功能

- 101 / 102 / 201 / 202 / 301 / 302 六間房
- 上月抄表自動承接，本月只輸入六個電表數字
- 每度電價可設定，電費即時計算
- 電費總表：上月抄表 / 本月抄表 / 金額
- 每房帳單：房租 + 水費 + 電費 + 其他費用
- 房租、水費固定沿用；其他費用只作用於當月
- 一鍵複製電費總表圖片與文字
- 一鍵複製每房帳單圖片與文字
- 本月還原
- 完成本月後自動進入下月
- 歷史月份保存與撤銷上次完成
- JSON 備份 / 還原
- PWA / 離線快取 / 手機主畫面安裝

## 資料策略

目前採 local-first：資料存在使用裝置瀏覽器的 localStorage，並提供 JSON 匯出備份與還原。

若未來需要跨手機同步，可再接雲端資料層；現有資料結構已保留升級空間。

## 部署

可直接部署至 Vercel 或 GitHub Pages。Vercel 不需要 build step，根目錄的 `index.html` 即為入口。
